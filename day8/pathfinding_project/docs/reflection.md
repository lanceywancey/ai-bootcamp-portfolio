# AI Review Reflection

- **Why AI-generated code may fail:** AI can misunderstand requirements, miss
  edge cases, or generate code that looks correct but behaves incorrectly.

- **Why automated verification is important:** Tests provide repeatable evidence
  that pathfinding and access control work as expected.

- **Strengths and weaknesses of AI tools:** AI is useful for generating test
  ideas and reviewing code, but its suggestions can still be incomplete or
  wrong and must be checked.

- **Why subsystem decomposition is useful:** Separating map loading,
  pathfinding, authentication, the web interface, and tests makes failures
  easier to locate and fix.
